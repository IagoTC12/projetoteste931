# avaliação ambiental pessoal

- site

- funcionara de forma manual
- tem como objetivo mostrar as pessoas quais e como seus habitos cotidianos afetam as mudanças climáticas e quando necessário, como mudar elas ou melhorá-las.
- o usuário pode comparar com os outros usuários no geral
- o usuário escreve sua atividade e ela será avaliada, assim atribuindo uma pontuação, aumentando quando for uma boa ação, nenhuma quando for neutra e perderá quando for prejudicial.
