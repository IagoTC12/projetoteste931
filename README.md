
# Avaliação Ambiental Pessoal

- Site com o objetivo de conscientizar as pessoas sobre como seus hábitos cotidianos afetam o meio ambiente e contribuem para as mudanças climáticas.
- Funcionará de forma manual, permitindo que os usuários escrevam suas atividades para serem avaliadas.
- Quando necessário, serão apresentadas sugestões de como mudar ou melhorar hábitos que prejudicam o meio ambiente.
- Os usuários poderão comparar seus resultados com os de outros participantes.
- Cada atividade registrada receberá uma pontuação de acordo com seu impacto ambiental: ações positivas aumentarão a pontuação, ações neutras não causarão alterações e ações prejudiciais resultarão na perda de pontos.
