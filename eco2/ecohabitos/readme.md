
# 🌱 Avaliação Ambiental Pessoal

- 🌍 **Objetivo:** conscientizar as pessoas sobre como seus hábitos cotidianos afetam o meio ambiente e contribuem para as mudanças climáticas.
- ✍️ **Funcionamento:** o site funcionará de forma manual, permitindo que os usuários registrem suas atividades para serem avaliadas.
- 💡 **Sugestões de melhoria:** quando necessário, serão apresentadas sugestões de como mudar ou melhorar hábitos que prejudicam o meio ambiente.
- 🏆 **Comparação entre usuários:** os participantes poderão comparar seus resultados com os dos demais usuários.
- 📊 **Sistema de pontuação:** cada atividade receberá uma pontuação de acordo com seu impacto ambiental:
  - 🟢 **Ações positivas:** aumentam a pontuação.
  - ⚪ **Ações neutras:** não alteram a pontuação.
  - 🔴 **Ações prejudiciais:** diminuem a pontuação.
